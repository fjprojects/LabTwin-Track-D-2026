This report maps the supplied official judging weights to working code and executed evidence. It does not predict or invent a judge score. See [compliance audit](TRACK_D_COMPLIANCE_AUDIT.md) for every mandatory item and remaining gaps.

| Category / official weight | Evidence available | Demonstration and tests | Remaining weaknesses |
|---|---|---|---|
